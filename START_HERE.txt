PATH 1 — FASTEST: Get your .exe in ~2 minutes (recommended)
------------------------------------------------------------------------
1. Install Node.js (free, one time): https://nodejs.org  -> "LTS" version
2. Unzip this file to a folder, e.g. C:\AIMarketingPro
3. Open Command Prompt (Win+R, type cmd, Enter) and run:

      cd C:\AIMarketingPro
      npm install
      npm run dist:win

4. Grab your program from the "dist" folder that appears:

   • AI Marketing Analytics Pro 1.0.0.exe        <- PORTABLE single-file
                                                    EXE. Copy it anywhere
                                                    (Desktop, USB stick).
                                                    Double-click = course.
   • AI Marketing Analytics Pro Setup 1.0.0.exe  <- Classic installer with
                                                    desktop shortcut.

   Either EXE is fully self-contained: all 8 modules, quizzes, 7 auto-
   graded labs, datasets, dashboard, and certificate work with zero
   internet. This zip was verified with `node scripts/verify_labs.js`
   (all 7 lab graders PASS).

------------------------------------------------------------------------
After unzipping, just double-click:

      app\index.html
